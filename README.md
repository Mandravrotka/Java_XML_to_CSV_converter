## Описание

Это веб-приложение Spring Boot предоставляет REST API для конвертации XML-файлов с данными об играх в CSV-файл, отсортированный по убыванию продаж. Проект включает валидацию входных данных, парсинг XML, обработку и генерацию CSV.

### Сборка проекта

```bash
mvn clean install
```

### Запуск приложения

```bash
mvn spring-boot:run
```

Приложение будет доступно по адресу: `http://localhost:8080`

### Тестирование через Swagger

После запуска приложения перейдите по адресу:

```
http://localhost:8080/swagger-ui.html
```

### Пример XML-файла

Корректный пример XML-файла можно найти по пути: `src\test\resources`
